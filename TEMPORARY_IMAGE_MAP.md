First-production images were each visually vetted against the catalogue page form (ÉLAN torso, SOLENNE bud, FORMA egg, BOATÉ hull, PÉTALE petals, VÉNUS conch-spiral, LIGNE slab, BLOC rectangle, HALO paddle, RIVE slats, ORBE slots, ÉCLAT carved rim, QUADRÉ squares, CERCLE discs); rejected candidates (infographics, text overlays, watermarks, mixed materials, wrong forms, cross-product duplicates) were never saved to `public/temporary-images/`. Each of the 14 production products uses its own unique file; the same product's file is intentionally reused across its homepage/gallery/detail/cart/wishlist cards.

All 38 files are distinct downloads. Cross-batch duplicates were detected and excluded before download: home-decor pin reused in living query, joinery pin reused in material/fingerjoint queries, chisel pin reused in poster query, grain pin reused in knots query, infographic pin reused in second chisel query, atelier interior reused in journal-hero query. Rejected candidates (upholstery, text overlays, watermarks incl. "Dola AI"/"SGT"/"OKEECHOBEE"/Pinterest chrome, brand labels incl. WoodRiver/osmo/Ohio Walnut Oil, stone-not-wood, collages, CGI, rusty nails) were never saved to `public/temporary-images/`.
